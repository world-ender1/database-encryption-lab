# database-encryption-lab

Đồ án môn Mật mã & An toàn thông tin (nhóm 3 người, 4 tuần). Hệ thống quản lý hồ sơ sinh viên nhỏ dùng dữ liệu giả: ứng dụng FastAPI mã hóa 3 trường nhạy cảm (`national_id`, `phone`, `address`) bằng AES-256-GCM trước khi ghi xuống PostgreSQL, rồi nhóm tự tấn công thử và đo hiệu năng để xem mã hóa tầng ứng dụng bảo vệ được gì, không bảo vệ được gì.
